# Pandas Student Performance Analysis

## About the Project

This project explores and analyzes student performance data using Python and Pandas. It demonstrates how to load, inspect, manipulate, and summarize tabular data.

## Project Objectives

* Load student data from a CSV file.
* Inspect and understand the dataset.
* Calculate total and average scores.
* Identify the top-performing students.
* Group and summarize student performance.

## Technologies Used

* Python 3
* Pandas
* Jupyter Notebook
* CSV

## Key Concepts

* Reading CSV files with `pd.read_csv()`
* Data inspection using `head()`, `info()`, and `describe()`
* Creating calculated columns such as `TotalScore` and `AverageScore`
* Sorting data using `sort_values()`
* Selecting the top three students
* Grouping and summarizing data with `groupby()`

## How to Run

1. Clone or download this repository.

2. Open the project folder in VS Code or Jupyter Notebook.

3. Install the required libraries if needed:

   `pip install pandas jupyter`

4. Ensure the CSV file is in the correct location.

5. Open the notebook and run the cells in order.
